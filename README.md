Boas-vindas ao README desse experimento com IA na veia 🚀

Esse mini-projeto é meu playground com a força do Claude Sonnet 4 utilizando Cursor, o editor inteligente que virou um híbrido de IDE + copiloto de código. Quis ver até onde o “vibe coding” (ou seja,
bombar um projeto só usando prompts no estilo papo com gente) dá energia pra automatizar o trivial e liberar a cabeça pro que importa.

🎯 Qual foi o lance da brincadeira?
Explorar o “vibe coding”: escrever cenário de interface em português, e ver o prompt virar código real e funcional.

Aprender na prática como comandar a IA: a deia é ver aonde podemos chegar sem colocar a mão no código, mesmo que não seja a melhor abordagem (por enquanto).

Liberar tempo do hack manual: tarefas repetitivas — tipo gerar páginas ou listas de forma sistemática — viram empurrão de prompt, e a IA faz o serviço pesado.

🤷‍♂️ O que rendeu?
Ritmo mais rápido pra protótipos, documentação, componentes repetidos.

Estudo de como fazer o IA colaborar sem virar “ghost coder”: o Dev ainda tem papel crítico de olhar, corrigir, questionar e finalizar.

Uma experiência bem real com o corpo, a mão e a mente no loop: Vim de experimentar; sai entendendo como IA pode ser coworker experimental.

🧠 Sobre o “vibe coding” na prática
Em vez de escrever cada linha, você escreve como se fosse para um colega: “Claude, pega isso e faz tal.”

A IA sugere bagulhos inline (como completar tags,Classes), corrige, propõe refactoring— mas o programador continua com cadência de humano.

É tipo comandar um copiloto que conhece TODO seu código — crave prompt + revisão como workflow padrão.

✨ Por que Claude Sonnet 4 + Cursor fazem sentido?
O Claude Sonnet 4 traz ganhos enormes de consistência, reconhecimento de contexto e raciocínio mais confiável em comparação com versões anteriores;

O Cursor, por sua vez, te dá profundidade: entende seu projeto inteiro, integra bem com extensões do VS Code e roda localmente;

O combo funciona tão bem que o termo “vibe coding” tem sido citado em relatórios de tendência, com empresas adotando o fluxo como forma de escalar desenvolvedores com mais leveza.
